# AI Video Studio Architecture\n\n## Overview\n\nAI Video Studio uses a microservices architecture with agent-based orchestration.\n\n## Components\n\n- **Frontend (Next.js)**: User interface for video creation and management\n- **Backend (FastAPI)**: REST API, authentication, orchestration\n- **Workers (Celery)**: Background processing for AI generation and rendering\n- **Database (PostgreSQL)**: Persistent data storage\n- **Cache/Queue (Redis)**: Job queue and caching\n- **Object Storage (S3)**: Media asset storage\n- **FFmpeg**: Video assembly and processing\n\n## Agent Workflow\n\n1. Prompt Enhancement Agent\n2. Script and Storyboard Agent\n3. Video Generation Agent\n4. Voice and Audio Agent\n5. Video Assembly Agent\n6. Quality Assurance Agent\n\n## Provider Interface\n\nAll video providers implement a common interface for swappability.\n
