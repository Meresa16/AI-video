# AI Video Studio\n\nA modern web application for generating high-quality videos from text prompts using AI agents.\n\n## Features\n\n- Text-to-video generation with configurable settings\n- AI agent orchestration (Prompt Enhancement, Script/Storyboard, Video Generation, Voice/Audio, Assembly, QA)\n- Provider-independent architecture (Runway, HuggingFace, self-hosted models)\n- Real-time progress tracking\n- User authentication and project management\n- Video preview and download\n\n## Tech Stack\n\n- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS, shadcn/ui\n- **Backend**: FastAPI, SQLAlchemy, PostgreSQL\n- **Workers**: Celery, Redis\n- **Media**: FFmpeg\n- **Storage**: S3-compatible object storage\n\n## Quick Start\n\n1. Copy .env.example to .env and configure\n2. Run with Docker Compose: docker-compose up --build\n3. Access frontend at http://localhost:3000, API at http://localhost:8000\n\n## Architecture\n\nSee [docs/architecture.md](docs/architecture.md) for details.\n\n## Development\n\n- Backend: cd backend && pip install -r requirements.txt && uvicorn app.main:app --reload\n- Frontend: cd frontend && npm install && npm run dev\n- Workers: cd workers && celery -A app.workers.celery worker --loglevel=info\n\n## License\n\nMIT\n
